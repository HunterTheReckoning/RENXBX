
# Command & Conquer Renegade - Xbox Homebrew Port
This is utilizing Source code from both EA's Renegade github, and NXDK - Xbox XDK.

## What it currently does
Use test cubes to test out culling, transparency, and Memory leak checking.
It now has a test for armature/Character model rendering and LOD test (Broken atm)
Terrain test - Set to M00_Tutorial.mix (Finnicky, missing interiors and lighting is off.)

## Requirements
You will need always.dat, always2.dat, and M00_Tutorial.MIX to run the prototype. IT IS STILL EARLY, EXPECT BUGS
